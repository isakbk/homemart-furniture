# HomeMart – Furniture & Decor

## Project Overview

HomeMart is a modern and responsive furniture and home décor e-commerce website. The project is designed to provide users with a clean and attractive shopping experience for furniture, home accessories, and décor products.

The website includes product browsing, category sections, product details, shopping cart interface, checkout layout, account screens, and responsive design for different screen sizes.

## Installation and Setup

```bash
git clone https://github.com/isakbk/homemart-furniture.git
cd homemart-furniture
npm install
npm run dev
```

## Build for Production

```bash
npm run build
npm run preview
```
